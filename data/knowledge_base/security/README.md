# knowledge_base/security — 信息安全规范语料

存放信息安全与合规类文档，是 RAG（Milvus）检索的语料来源之一。

内容范围（示例）：
- 信息安全管理制度
- 数据分级分类与访问控制规范
- 账号、密码、密钥管理要求
- 终端与网络安全规范
- 数据出境与隐私合规要求
- 安全事件响应流程

## 数据来源约束

- 只允许使用**公开**的信息安全标准 / 规范 / 指南，或明确标注为合成的企业知识文本。
- 每份文档必须登记到 `THIRD_PARTY_LICENSES.md`（含许可证与署名要求）。
- 禁止放入任何真实企业的未公开内部文件。
